# ancaveman

Предельное сжатие ответов для Claude Code и других агентов. Жёстче, чем `caveman`: таблицы вместо прозы, предел десять слов в предложении.

Умирает только форма. Код, пути, числа, ошибки и отрицания сохраняются дословно.

## Установка

Как скилл:

```
npx skills add zxraven/ancaveman
```

Как плагин Claude Code:

```
claude plugin marketplace add zxraven/ancaveman && claude plugin install ancaveman@ancaveman
```

## Использование

```
/ancaveman
```

Работает также по словам «ещё короче», «максимально сжато».

Выключение: «стоп» или «обычный режим».

## Чем отличается от caveman

| Правило | caveman | ancaveman |
|---|---|---|
| Предел предложения | 20 слов | 10 слов |
| Три и более сопоставимых фактов | проза | таблица обязательна |
| Проза | по умолчанию | только там, где связи несут смысл |

## Что не сжимается никогда

1. Предупреждения о безопасности.
2. Подтверждение необратимого действия.
3. Порядок шагов, который фрагментом можно перепутать.
4. Повторный вопрос пользователя.
5. Текст, который сохранится вне чата: код, комментарии, коммиты, документы, задачи, сообщения другим людям.
6. Вопрос пользователю и выбор из вариантов.
